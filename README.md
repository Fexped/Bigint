BigInt — Números inteiros de tamanho ilimitado
Nesse projeto o objetivo da tarefa era criar/implementar a classe big int que funcionasse com uma calculadora(main) ja fornecida pelo o professor.
E uma classe para representar e manipular números inteiros com quantidade ilimitada de dígitos, incluindo operações aritméticas, comparação, incremento/decremento, inversão de sinal, módulo, fatorial e operações de divisão.
Se trata de um projeto feito em conjunto entre o professor e o aluno!!
